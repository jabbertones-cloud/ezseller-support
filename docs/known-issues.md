## Known availability boundaries (not product incidents)

Reviewed November 17, 2026.

- **ChatGPT listing discovery:** EzSeller's published plugin can be opened by [direct link](chatgpt-plugin.md), even if it does not appear in a particular ChatGPT plugin directory search. Search placement and account eligibility require separate verification.
- **Native Apple beta:** iPhone and Mac applications exist as beta/release-preparation surfaces; general App Store availability and public customer Amazon sign-in are not verified. See [Apple beta support](apple-apps.md).
- **Public Amazon application authorization:** Public EzSeller SP-API/LWA approval is distinct from private owner testing through CommerceOS; do not exchange customer credentials or reuse owner tokens. Check [current product status](current-product-status.md).
- **2027 fee calculations:** The product source defines three published-schedule estimation tools. Live MCP availability depends on the deployed version and client permissions. These estimates are not account charges. See [2027 fee guide](amazon-fees-2027.md).
- **Agency features:** Source support for client scoping does not certify external agency production onboarding or complete multi-account isolation acceptance.

These are documented support limits, not declarations of an outage. An account-specific failure still needs authenticated diagnostics and private handling as appropriate.
