# Support

## Public support
Use GitHub Issues for reproducible product/documentation problems that can be discussed without private account evidence. Search existing problem records and resolved cases first.

## Authenticated diagnosis
When the answer depends on current account/provider state, use EzSeller's authenticated diagnostic path from https://ezamazon.smatdesigns.com/support.

## Private support
Use the private support route on the canonical website when the case requires credentials, seller/customer/order identifiers, private financial evidence, or raw private logs.

## Security
Do not open a public issue for a vulnerability or suspected secret exposure. Follow SECURITY.md.
