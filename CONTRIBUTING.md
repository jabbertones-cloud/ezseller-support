# Contributing public knowledge

This repository accepts improvements to public EzSeller support knowledge, problem classification, troubleshooting, documentation, and sanitized resolved cases.

## Before contributing
1. Read `AGENTS.md` and `docs/PUBLICATION-SAFETY.md`.
2. Search for an existing `AMZ.*` problem ID.
3. Prefer improving the existing problem record over creating a duplicate concept.
4. Do not add private account evidence, credentials, raw logs, proprietary source, or unsupported product/provider claims.

## A useful contribution
A strong troubleshooting or resolved-case contribution includes:
- customer-visible symptom,
- stable problem ID,
- official provider terminology,
- safe diagnostic steps,
- what was actually observed vs inferred,
- safe action boundary,
- verification step,
- source/provenance,
- last verified date when behavior can drift.

## What does not belong here
Private support transcripts, customer-specific evidence, secrets, speculative provider behavior, thin SEO pages, or content created only to target keyword variants.
