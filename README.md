# EzSeller Support & Knowledge

Public support knowledge for **EzSeller** — helping Amazon sellers understand listings, inventory, marketplaces, reports, reconciliation and related seller problems without guessing through Seller Central.

> This repository contains public documentation, sanitized problem knowledge, and support workflows. It does **not** contain EzSeller source code, credentials, customer/order data, or private seller evidence.

## Start here

- **I have a general/reproducible seller question:** search this repository's problem knowledge and resolved cases.
- **My answer depends on current Amazon seller/marketplace state:** use EzSeller's authenticated diagnostic experience.
- **My issue contains seller, customer, order, financial or other sensitive evidence:** use private support; do not post it publicly.
- **I am an AI agent:** read `AGENTS.md` before diagnosing or proposing a public support case.

Canonical product/support website: https://ezseller.smatdesigns.com/support

## How the knowledge system works

Customer wording → stable `AMZ.*` problem ID → Amazon terminology → public explanation → authenticated diagnostic → safe action → verification → support case when needed → sanitized resolution.

The website is the canonical public explanation and discovery surface. This repository is the public agent/community/evidence layer.

## Public safety

Never post credentials, authorization tokens, seller/customer identifiers, order data, private financial evidence, private source code, raw private logs, or other sensitive account evidence in a public issue.

## Status

This repository is being populated from a verified problem ontology. Content is intentionally conservative: a historical case is not proof of current Amazon behavior, and a test is not proof of current live seller state.
